# Homebrew tap

```sh
brew install alparslansemiz/tap/serit   # Touch Bar that stays put
brew install alparslansemiz/tap/veda    # quit apps when their last window closes
```

Both build from source on your Mac. Start them with `brew services start serit` or `brew services start veda`, then allow them under System Settings → Privacy & Security → Accessibility.

| Formula | Project |
| --- | --- |
| `serit` | [AlparslanSemiz/Serit](https://github.com/AlparslanSemiz/Serit) |
| `veda` | [AlparslanSemiz/Veda](https://github.com/AlparslanSemiz/Veda) |
